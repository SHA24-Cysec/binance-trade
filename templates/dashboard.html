⚙️ Parameter Strategi

🧪 Backtest Parameter (data historis Binance)

Uji parameter exit/entry pada satu simbol memakai data historis. Backtest ini tidak mensimulasikan persaingan antar-simbol seperti bot asli (yang memindai seluruh pasar dan hanya memilih satu kandidat terbaik) -- gunakan untuk membandingkan set parameter pada simbol yang sama, bukan sebagai jaminan hasil di masa depan. Backtest bersifat read-only, tidak menyentuh bot/posisi yang sedang berjalan. Rentang hari tidak dibatasi -- isi berapa saja, batas alaminya hanya sejak kapan simbol itu mulai listing di Binance. Rentang yang sangat panjang akan memakan waktu proses lebih lama.
